# Livro API 📚 - Online!

API rodando em: https://livro-api-9t7z.onrender.com/swagger-ui.html

Endpoints:
- GET /livros
- POST /livros

Feito com Java + Spring Boot + Docker + Render

## 🚀 Tecnologias
- **Java 17**
- **Spring Boot (Primavera)** - Framework principal
- **Spring Data JPA / Hibernate (Hibernar)** - ORM para banco de dados
- **REST API (Repousante)** - Endpoints REST
- **SQL / H2 Database** - Banco de dados
- **Maven** - Gerenciador de dependências

## 📦 Endpoints
- GET /livros - Lista todos
- GET /livros/{id} - Busca por ID
- POST /livros - Cria um livro
- PUT /livros/{id} - Atualiza um livro
- DELETE /livros/{id} - Deleta um livro
